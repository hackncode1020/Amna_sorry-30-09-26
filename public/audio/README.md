# Background Music Folder

This folder (`public/audio/`) is dedicated for background apology music and audio tracks.

- You can place your custom audio file here (e.g. `apology-song.mp3`).
- The application also includes an automated, zero-latency Web Audio API ambient peaceful melody generator (`src/utils/ambientAudio.ts`) that plays soothing music with the floating speaker button 🔊 at the bottom right.
